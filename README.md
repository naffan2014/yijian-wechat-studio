# 一见 · 微信公众号排版工作台

一个跑在本机的微信公众号写作工具：左边写 Markdown，右边实时预览公众号里的最终效果，选好模板后一键复制或写入草稿箱。所有排版样式都会转成内联样式，粘贴到微信编辑器里不会掉格式。

零 npm 运行时依赖、无需构建、无需 `npm install`，Node.js 18+ 直接运行。所需浏览器转换库已随项目本地内置，不依赖 CDN。

## 功能

- **26 套排版模板**：6 套一见原创模板与 20 套花生编辑器开源主题，保留各自的标题、正文、引用、列表、代码和表格样式，支持字号、行距、强调色微调。
- **17 个原创样式组件**：样式中心提供章节标题、导语、引用、卡片、步骤、目录、双栏、关键数字、关注和收尾等组件，可按分类浏览、搜索、收藏并插入正文。
- **富文本与文档导入**：直接粘贴网页等富文本，或导入 DOCX、HTML、Markdown、TXT；标题、加粗、列表、表格、链接等会转换为 Markdown，内嵌图片自动进入本机素材库。
- **文章标题与作者**：标题和作者直接位于写作画布顶部，修改后自动保存，并同步到本机文章列表与手机预览。
- **所见即所得**：手机壳预览与复制/发布使用同一份 HTML，标题、封面、日期、正文、留白都按公众号阅读页还原。
- **素材库**：拖拽或点击上传图片，自动压缩到公众号可接受的大小；粘贴截图可直接上传并插入正文。
- **公众号图库**：只读获取公众号后台的永久图片素材，每页 20 张，支持预览、跨页多选并一次插入正文；不会重复转存，也不会修改或删除线上素材。
- **发布记录**：在「文章 → 发布记录」查看公众号已发布文章，以日期档案卡片展示标题、摘要、作者和多图文篇序；支持加载更多、查看详情、复制链接及新窗口打开原文。
- **草稿箱**：在「文章 → 草稿箱」只读查看公众号草稿，显示封面、标题、摘要、作者、更新时间和多图文篇序，支持分页与复制草稿 ID；不会修改或删除线上草稿。
- **图文 / 贴图两种内容**：新建时可选择「新建文章」或「新建贴图」。贴图与文章共用同一套页头、工具栏、写作画布和页脚：文案在画布顶部直接书写，图片区域在下方管理；贴图使用 1–20 张图片加一段纯文案，首图即封面，图片可拖拽排序；手机预览按小绿书图片消息展示，发布时写入公众号草稿箱。
- **封面工坊与裁剪**：用文章标题生成 1080 × 460（2.35 : 1）首图，6 种配色、两种版式，可下载或直接设为封面；发布页还可以直接从正文的本机图片或公众号图库图片中选择封面。选到比例不合适的图片时，会自动打开与公众号一致的 2.35 : 1 固定裁剪框，支持拖动、滚轮或滑块缩放，保存为 1080 × 460 的本机封面。
- **AI 美化**：接入任意 OpenAI 兼容模型，一键优化排版、润色文字或精简篇幅；支持选中局部处理、结果预览、应用后撤销。
- **AI 续写 / 扩写**：在正文里选中一句话，旁边会浮出「AI 续写」小胶囊，点一下让模型顺着这句话补写一小段；贴图文案里同样操作会显示「AI 扩写」，生成内容插到选中句所在段落之后。确认后作为新段落插入，未配置模型时不会出现。
- **两种发布方式**：
  - 复制到公众号：富文本复制，保留全部内联样式；配置接口后正文图片会自动上传到微信，未配置时只复制文字排版。
  - 发布草稿：自动上传正文图片与封面，写入公众号草稿箱，再到公众平台确认群发。
- **多公众号账号**：可添加多个公众号账号，每个账号独立保存名称、默认作者、AppID 与 AppSecret；文章绑定账号保存，顶栏一键切换，图库、草稿箱、发布记录与发布目标都跟随当前账号。
- **本地草稿**：自动保存到本机 `data/`，刷新不丢；支持导入 DOCX、HTML、Markdown、TXT，导出 Markdown 和完整 HTML。
- **纯本机运行**：服务只监听 `127.0.0.1`，AppSecret 与 AI API Key 只保存在本机且不会回传到浏览器。

## 快速开始

```bash
# 在项目目录
npm start
# 或
node server.js
```

打开 <http://127.0.0.1:5188>。

首次启动会自动创建 `data/`、`uploads/`，并写入一篇示例文章和两张示例配图。修改代码时可用 `npm run dev`（`node --watch`）自动重启。

环境要求：Node.js ≥ 18（用到内置 `fetch`、`FormData`、`Blob`）。推荐最新版 Chrome / Edge / Safari。

## 写作与排版

正文使用 Markdown，右侧会实时渲染：

| 写法 | 效果 |
| --- | --- |
| `## 标题` / `### 标题` | 二级 / 三级标题（按模板装饰） |
| `**加粗**`、`*斜体*`、`~~删除线~~`、`==荧光==` | 行内强调 |
| `> 引用` | 引用块 |
| `- 列表` / `1. 列表` | 无序 / 有序列表 |
| `![图注](/uploads/xxx.jpg)` | 图片 + 图注 |
| `[文字](https://...)` | 链接 |
| ` ``` ` 代码块 | 代码块 |
| `---` | 分割线 |
| `\| 表格 \|` | GFM 表格 |
| `:::tip 标题`<br>内容<br>`:::` | 提示卡片；样式中心还会自动写入章节、导语、步骤、双栏等容器 |

常用快捷键：`⌘S` 保存、`⌘B` 加粗、`⌘I` 斜体、`⌘K` 插入链接、`Esc` 关闭弹窗。

排版流程：

1. 左侧「模板」在「一见原创」与「开源主题」之间切换，选一套版式，按需调整字号、行距、强调色。
2. 「样式」按分类或关键词找到组件，点「插入」写入光标位置；点星标可收藏，组件预览会跟随当前主题和强调色。
3. 「素材」上传图片，点「插入」写入正文；也可以直接粘贴截图，或点「公众号图库」选择线上永久图片素材。正文工具栏的图片弹窗同样提供图库入口。
4. 「封面」用封面工坊生成首图，或从本机素材库选一张横图；比例不是 2.35 : 1 时会先进入裁剪，拖动取景后保存。
5. 右侧预览确认效果，然后「复制到公众号」或「发布草稿」。

## 富文本粘贴与文档导入

在编辑器中直接粘贴网页、文档等富文本，会优先读取剪贴板里的 HTML 并转换为 Markdown；没有富文本时仍按纯文本或截图处理。点击「导入文档」可选择 `.docx`、`.html`、`.htm`、`.md`、`.markdown`、`.txt`，单个文件不超过 30MB，导入后会创建一篇新文章。

- 保留常见标题、加粗、斜体、高亮、列表、表格、链接和代码结构，清理脚本、表单、内嵌框架及危险链接；复杂 Word 版式不会原样复刻。
- DOCX 和富文本中的内嵌图片会逐张压缩、上传到本机素材库，再插入正文；转换失败的图片会被移除并计数提示。
- HTTP/HTTPS 外链图片只保留原地址，不会由服务端抓取或自动转存。正式发布前建议从素材库换成本地图片，避免外链失效或微信无法读取。
- DOCX/HTML 使用同一套安全转换管线；第三方脚本全部从本机 `/vendor/` 加载，离线也能完成转换。

## AI 美化（可选）

文章页顶部点「AI 美化」，第一次使用时在弹窗下方填写模型接口：

- **接口地址**：任意 OpenAI 兼容的 `Base URL`，例如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`、`http://127.0.0.1:11434/v1`（Ollama）。只填域名时，如果该路径返回 404，会自动再尝试一次 `/v1`；直接粘贴带 `/chat/completions` 的完整地址也能识别。
- **模型名**：可手动填写，也可点「获取模型列表」从 `/models` 拉取后下拉选择。部分网关只开放对话接口、没有 `/models`，此时手动填写模型名即可。
- **API Key**：只保存在本机 `data/settings.json`（权限 `600`），界面只显示“已保存”，不会回显。本机 Ollama 可以留空。
- 内置 DeepSeek、OpenAI、通义千问、智谱、Moonshot、硅基流动、Ollama 预设，选预设后仍可改地址和模型名。

三种处理方式：**排版美化**只调整结构、**文字润色**同时修语病、**精简提炼**压缩篇幅。若先在编辑器里选中一段文字，再打开弹窗，可以只处理并替换这一段。

结果会先在弹窗里渲染预览，确认后点「应用到正文」；应用后可以直接「撤销本次修改」。正文超过 20,000 字符时建议局部处理或分篇。带推理过程的模型出字较慢，弹窗会显示已用时，单次请求最多等待 5 分钟。AI 调用会把选中的正文发送给你配置的模型服务商，除此之外不会上传到其他地方。

## AI 续写（可选）

配好上面的模型后，在编辑器里用鼠标选中一句话，松开鼠标时旁边会出现「AI 续写」小胶囊。点一下即可让模型顺着这句话补写约 80–160 字，结果先显示在浮层里：

- 点「插入」会把续写内容作为新段落接在选中句之后，并立即自动保存、刷新预览；
- 不满意可以点「重试」，或点「取消」/按 `Esc` 关闭；滚动正文、点击别处也会收起浮层；
- 没有填写接口地址或模型名时，这个胶囊不会出现，与 AI 美化共用同一套配置；
- 发送给模型的内容包括你选中的句子、它前面约 2,000 字的上下文和文章标题，不会上传到别处。

**贴图 AI 扩写**使用同一套配置和同一个浮层：在贴图文案里选中一句，浮层会显示「AI 扩写」，生成约 60–140 字的纯文本，插入到选中句所在段落之后，原句保持不动；也可以不选中，直接点右上角「AI 扩写」，让模型接着整段文案往下写。结果不包含 Markdown 标记，超过 1000 字上限时会自动截断并提示。第一次使用若还没配置模型，会先打开一个精简的模型配置弹窗，保存后自动继续扩写。

服务端接口是 `POST /api/ai/continue`，传 `format: "plain"` 时按贴图纯文案处理；密钥同样只保存在本机，不会回传到浏览器。

AI 美化与 AI 续写都会尽量关闭模型的思考过程，让返回内容直接就是最终文案：MiniMax、GLM、Kimi、豆包等使用 `thinking: disabled`，Qwen 使用 `enable_thinking: false`，GPT-5 使用最小推理量。网关若拒绝这些参数，会自动去掉后重试一次；本身无法关闭思考的推理模型（如 DeepSeek Reasoner）保持默认。

## 配置公众号接口（可选）

只使用「复制到公众号」时可以不配置接口，但正文图片需要粘贴后手动补。要自动传图或写入草稿箱，需要：

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 设置与开发 → 基本配置，获取 **AppID** 和 **AppSecret**。
2. 在同一页面的「IP 白名单」中加入本机的公网 IP。家宽 IP 会变化，报 `40164` 时回来更新白名单。
3. 公众号需具备草稿箱与素材接口权限（通常需要已认证的公众号）。
4. 在右上角设置里编辑当前账号，填入公众号名称、作者、AppID、AppSecret，点「保存并测试连接」。

接口凭证保存位置：`data/settings.json`（权限 `600`）。服务端只返回 `hasSecret`，不会把 AppSecret 发回浏览器。

### 多账号管理

右上角设置打开「账号与接口」，可以添加、编辑、删除多个公众号账号：

- **文章绑定账号**：每篇文章归属一个账号，文章列表只显示当前账号的文章；新建文章自动归入当前账号。切换账号后，画布会打开新账号下最近编辑的一篇，没有文章时自动新建一篇。
- **顶栏快速切换**：顶栏账号按钮列出所有账号，点选即切换；公众号图库、草稿箱、发布记录、复制与发布的目标都跟随当前账号，发布弹窗里会明确显示目标账号名。
- **凭证相互独立**：每个账号各自保存 AppID / AppSecret，access_token 按账号独立缓存；不填凭证的账号也能用来纯本机写作和复制文字排版。
- **删除保护**：至少保留一个账号；删除还有文章的账号时，会先提示将连带删除的本机文章数量，确认后才执行。公众号线上内容不受任何影响。
- **贴图素材按账号隔离**：贴图里引用的公众号图库素材记录来源账号，只有发布到同一账号时才复用 `media_id`，跨账号发布自动改走下载重传。
- 旧版本升级后，原有单账号配置与全部文章会自动迁移为第一个账号，无需手动操作。

配置完成后，「素材 → 公众号图库」会通过 `batchget_material` 只读分页获取**永久图片素材**。临时素材、图文消息内图片以及其他素材类型不会出现在图库中。选中的图片直接使用微信返回的 URL 插入正文，复制或发布时不会重复上传。发布页「从正文选择封面」会同时列出正文里的本机图片和公众号图库图片；选用公众号图片时，服务端会从微信 CDN 下载后按永久素材重新上传，作为本次草稿的首图。选到比例不是 2.35 : 1 的封面会先打开裁剪框（与公众号后台的固定比例取景一致）：拖动图片选择保留区域，滚轮或滑块缩放，确认后输出 1080 × 460 并存回本机素材。公众号图库图片通过本机同源接口 `/api/wechat/image` 读取后再裁剪，避免浏览器 canvas 跨域，也不会把图片发给第三方。

### 查看草稿箱

打开「文章 → 草稿箱」，会通过微信 `draft/batchget` 只读读取公众号草稿箱，请求带 `no_content: 1`，不拉取正文 HTML。列表显示封面、标题、摘要、作者和更新时间：图文草稿标注为 Draft，图片消息草稿标注「图片消息 · N 张图」；点击卡片可查看摘要或贴图文案，多图文草稿会展示图文顺序，并复制草稿 ID。这里没有修改或删除操作，线上草稿仍需到公众号后台处理。

草稿箱读取接口的权限门槛低于发布记录：个人公众号通常也能读取草稿列表（本机实测返回 200），但 `freepublish/batchget` 仍会返回 `48001`。如果你在草稿箱看到 48001，说明当前账号连草稿接口也未开放，可在错误卡片里点「检查配置」确认凭证与 IP 白名单。

### 查看已发布文章

打开「文章 → 发布记录」，首次进入会自动读取公众号发布档案，也可以手动刷新或继续加载更多。列表按日期展示文章标题、摘要和作者，多图文发布会展开为单篇并标注篇序；点击卡片可查看完整摘要、发布时间和原文链接，并复制链接或在新窗口打开原文。

发布记录通过微信 `freepublish/batchget` 接口只读获取，请求使用 `no_content: 1`，不会拉取已发布正文。这里展示的是公众号线上发布记录，不包含仅保存在本机的草稿，也不提供删除或修改线上文章的操作。该接口目前仅支持已认证服务号，并需要公众号具备相应接口权限；个人公众号或订阅号调用时微信会返回 `48001`。

### 发布贴图（图片消息）

在「文章」面板点「新建 → 新建贴图」进入贴图编辑器，布局与文章编辑器一致：顶部是标题与作者，工具栏提供「添加图片 / 公众号图库」，画布顶部直接写纯文案，下方管理图片。添加 1–20 张图片，拖动调整顺序，首图自动作为封面；也可以把本机素材直接点进贴图，或将图片拖到编辑器里。贴图不使用文章模板、样式组件和 2.35 : 1 封面，侧栏会锁定「模板 / 样式 / 封面」，只保留「素材」和「文章」。

发布时调用微信 `draft/add` 的 `article_type: "newspic"`，图片放在 `image_info.image_list`，每张图片先转为永久素材。公众号图库里的图片如果自带 `media_id` 会直接复用，避免重复上传。接口只写入草稿箱，**不会自动发表**；微信的 `freepublish/submit` 官方只描述图文草稿，个人主体和未认证账号通常没有发布接口权限，因此贴图仍需到公众号后台手动发表。

贴图侧限制：标题 ≤ 32 字符、作者 ≤ 8 字符、文案 ≤ 1000 字、图片 1–20 张且单张 ≤ 1MB（JPG / PNG）。草稿箱读取接口对图片消息的多图回显不稳定，工具不承诺在「草稿箱」面板完整还原贴图。

### 微信侧的限制（工具已做校验）

- 草稿正文 HTML ≤ 20,000 字符、≤ 1MB；
- 正文图片仅支持 JPG / PNG，单张 ≤ 1MB（上传前会自动压缩）；
- 封面按 2.35 : 1 生成（1080 × 460）；
- 公众号会清洗正文最外层容器的背景色；正文用双层 section 兜底，模板底色和导入主题的背景纹理在复制或发布后仍会保留；
- 标题 ≤ 64 字符，作者 ≤ 8 字符（超出会截断并提示），摘要 ≤ 120 字符；
- 贴图（图片消息）标题 ≤ 32 字符、文案 ≤ 1000 字、图片 1–20 张，单张 ≤ 1MB 且仅支持 JPG / PNG，首图即封面；
- 草稿接口只写入草稿箱，**不会直接群发**，需要到公众平台预览确认后手动发表；
- 接口有频率限制，图片较多时发布可能需要十几秒，请勿关闭页面。

```text
data/
  articles.json   文章草稿（Markdown、模板、封面、状态、所属账号 accountId）
  uploads.json    素材元数据
  settings.json   账号列表 accounts、当前账号 activeAccountId 与 AI 接口配置（含密钥，权限 600）
uploads/          上传的图片与生成的封面
```

备份时复制 `data/` 和 `uploads/` 即可。`.gitignore` 已排除这两个目录，避免把密钥和草稿提交到仓库。样式中心的收藏保存在当前浏览器的 `localStorage`，不属于文章数据，换浏览器或设备后需要重新收藏。

## 常见问题

**复制后图片是空白 / 只剩文字？**  
未配置接口时，微信读不到本机 `/uploads/` 图片，工具会明确提示并只复制文字。配置接口后复制会自动上传图片；也可以复制后在微信编辑器里手动插入。

**发布时报 40164？**  
本机公网 IP 不在公众号后台的 IP 白名单里，按提示把返回的 IP 加入白名单。

**报 40001 / 40013 / 48001？**  
分别是凭证失效（检查 AppSecret）、AppID 不正确、接口未授权（公众号类型或认证状态不满足）。

**正文超过 20,000 字符？**  
精简内容或拆成多篇；工具会在发布前拦截并给出实际字符数。

**换电脑后草稿不见了？**  
草稿只存在本机 `data/`，复制该目录和 `uploads/` 到新机器即可。

## 安全说明

- 服务绑定 `127.0.0.1`，局域网内其他设备无法访问；
- AppSecret 与 AI API Key 只落盘到本机，接口响应中始终脱敏；
- AI 美化、AI 续写与贴图 AI 扩写只在你主动点击时，把待处理正文/文案（续写和扩写还包括选中句前约 2,000 字上下文）发送给你配置的模型接口；
- 打开公众号图库或发布记录时，只向微信请求对应的只读列表，不上传文章；发布/复制时才会按功能需要把图片和正文发送给微信接口；
- 选用正文里的公众号图片作封面或裁剪时，服务端只会下载微信 CDN（`*.qpic.cn`、`*.wx.qq.com`）的 HTTPS 图片，限制 10MB 并校验 JPG / PNG 内容，不会抓取其他网站的外链图片；裁剪用的 `/api/wechat/image` 只读代理同样遵守这个白名单；
- 除上述主动操作外，不会向任何第三方上传内容；不要把 `data/settings.json` 分享给他人，怀疑泄露时请在公众平台重置 AppSecret。
